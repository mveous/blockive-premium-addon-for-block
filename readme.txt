== Description ==

**Blockive - Premium Addon For Block** is an essential suite of premium Gutenberg blocks and a powerful Template Builder for WordPress. Create stunning, fast, and responsive websites with ease—no bulky page builders or coding required.

Every block is engineered with performance and clean code standards in mind, ensuring minimal asset footprints, mobile-first responsive controls, and built-in accessibility (a11y).

---

### Key Features

* **Lightweight & High Performance**: Clean assets loaded conditionally on pages where blocks are used.
* **Full Template Builder**: Design custom single post and page templates with dynamic template blocks and display conditions.
* **Responsive Styling**: Mobile, tablet, and desktop controls for spacing, typography, borders, and layouts.
* **Modern Design Controls**: Gradients, box shadows, text shadows, animations, color states, and hover effects.
* **Accessible (A11y)**: Built-in keyboard navigation, ARIA attributes, and semantic HTML markup.
* **SEO Optimized**: Schema.org structured data support for FAQ and template blocks.

== Installation ==

1. Upload the `blockive-premium-addon-for-block` folder to the `/wp-content/plugins/` directory, or install it via the WordPress Plugins screen (Plugins > Add New).
2. Activate the plugin through the Plugins menu in WordPress.
3. Open any page or post editor and search for "Blockive" in the block inserter.

== Frequently Asked Questions ==

= Are all blocks mobile-responsive? =
Yes. Every block is mobile-first and includes dedicated responsive breakpoints for desktop, tablet, and mobile devices.

= Does Blockive slow down my website? =
No. Blockive enqueues CSS and JavaScript assets on demand, only loading the assets required for the specific blocks used on that page.

= Can I use Blockive with any WordPress theme? =
Yes. Blockive works with all standard block themes (Full Site Editing) and classic themes supporting the Gutenberg block editor.

= How do I create custom single post templates? =
Go to Blockive > Templates in your WordPress admin dashboard, create a new template, set your display conditions, and build the layout using the Template Blocks.
